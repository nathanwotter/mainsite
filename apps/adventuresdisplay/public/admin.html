Household administration

Display & rotation

The default rotation spends 90% of its time in Pure or Ambient Photos. Edit mode durations, enabled modes, overlay layout, font size, weather coordinates and night hours below. The frame’s Display menu provides the same controls as a touch form.

Private source connections

Saved subscription URLs are encrypted server-side and are never returned here. Blank fields keep existing connections. Use the recipes-only Plan to Eat URL. All recipes are treated as dinners.

The iCloud adapter also requires server opt-in. It uses undocumented endpoints, may break, and has not been verified with your album. An invited-only album cannot be read by this server adapter.

Use [] to disconnect all calendars. Set mealMirror=true for a Google calendar that subscribes to Plan to Eat. Sources must use server-allowlisted hosts.

Display authorization

On the kitchen iPad, sign in here, name it, then authorize it. This replaces the short administrator session with a 90-day, read-only display session.
