# Accommodation Letter Notification Reply

Use this response category only for a Disability Resources Office message whose subject contains `Accommodation Letter Notification` and whose message or attached letter reliably identifies both the student and the course.

## Drafting rules

- Create the reply draft in the notification's existing Gmail thread and send it only to the student. Do not copy the Disability Resources Office. If the notification supplies the student's email address in its body rather than its recipient headers, use that address. If the student's address cannot be reliably obtained from the notification or thread, create no draft and flag the message for Nathan.
- Use the student's preferred or first name as provided. Do not infer a shortened name.
- Insert the course prefix and number exactly as given, such as `COM 110`. Do not add a section number unless Nathan asks for it.
- Do not restate, summarize, question, or disclose the student's accommodations in the body.
- Keep the wording below, substituting only the student's name and course prefix and number:

  `Hi, [student name]! I reviewed your accommodation letter; thanks for submitting it. Would you like to chat about it after class sometime? I don't anticipate any problems meeting your needs in the course, but want to be sure your questions are answered if you have any.`

  `See you in [class prefix and number] soon. Hope you're doing well!`

- Preserve the paragraph break between those two parts.
- Let Gmail apply Nathan's configured university signature when draft creation supports it. Preserve that signature exactly and do not duplicate it. Add no separate spacer before a signature whose source HTML already begins with a line break; the rendered draft should have one blank line, not two, between the final body paragraph and `Nathan`. If Gmail does not supply the signature, use the verified current signature according to the main skill's signature rule. If the signature cannot be verified, end with `Nathan` and report the limitation.
